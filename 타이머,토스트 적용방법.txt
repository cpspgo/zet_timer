'''전체 상품 토스트 메세지 적용방법'''

디자인관리 -> 상품 상세페이지 -> 상품 상세정보 안내 -> 상품_상세정보 상단 안내
 -> Editor 에서 HTML로 변경 -> 토스트메세지파일의 코드를 맨위에 붙여넣기
 -> 쇼핑몰 정보 저장 -> 쇼핑몰 바로 적용

※주의사항
Editor에서 HTML로 변경 후 코드 붙여넣고 다시 Editor로 변경하지마세요.
(플렉스지 특성상 스크립트 적용안되지 않아 토스트메세지가 한번만 출력됩니다.
단, 개별상품 타이머는 외부서버에서 코드를 불러오기 때문에 변경해도 상관 없습니다.)
